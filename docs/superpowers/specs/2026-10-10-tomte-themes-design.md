# Tomte: five more themes

2026-10-10. The user asked for five more themes before the theme picker ships: the old pre-1.2 look ("the old
default") and four new ones. One agent builds each theme; Claude reviews and reports once at the end. No commit before
the in-game check.

## Groundwork (done by Claude before the agents start)

So five agents can work in parallel without touching the same files:

- **One file per theme.** `Core/Theme.lua` is now the registry and the color/font API. Each theme is
  `Themes/<Key>.lua` calling `ns.Theme.Register(key, def)` (`label`, `order`, `colors`, `fonts(locale)`, `panel`,
  optional `art`, `media`, `fontBump`; documented above `Theme.Register`). Blizzard default and Cartographer moved to
  `Themes/Blizzard.lua` and `Themes/Cartographer.lua` unchanged. The TOC lists every theme file right after
  `Core/Theme.lua`.
- **Panel art driven by the theme.** `UI.Panel`'s layered look (`panel = "art"`) reads `Theme.art`: glow, corner art
  (`contours`), grain, vignette, outer edge, rule inset and alpha, title ornaments, and whether the Background opacity
  setting applies. Each layer can be turned off (alpha 0). `media` lets a theme swap any of the four textures
  (grain, contours = corner art, flourish, glow) for its own. `panel = "blizzard"` is still the tooltip nine-slice.
- **Tests cover every theme.** `tests/test_theme.lua` loads every `Themes/*.lua` from the TOC and checks for each:
  all 18 color roles in range, no unknown roles, minimum contrast against the fill (text 9, heading 7, textMuted 4.5,
  textFaint 2.8, accent 4.5, status colors 4.2, frame 2; calibrated on the two existing themes), known `art` keys,
  media and font files exist, and no own font files on Korean/Chinese clients. Theme files may hold numbers and font
  paths (the source scan skips `Themes/`).
- Dropdown order: Blizzard default 1, Classic 2, Cartographer 3, then Frost 4, Forge 5, Emerald 6, Void 7.

## The five themes

| Key | Brief |
| --- | --- |
| `classic` | The look before the Cartographer redesign (before commit 8906b7a): near-black flat panels, warm gold (1, 0.82, 0.45) headings, accents and 1 px borders, light grey text, the client's fonts, no texture layers. Faithful to the old code, not reinterpreted. |
| `frost` | Northrend ice: deep blue-slate panels, frost-white text, glacier-blue accent, silvery steel frames, rime or ice crystals in the corner art. |
| `forge` | A dwarven forge: dark iron and soot, warm text, ember-orange accent, bronze or copper frames, hammered-metal grain. |
| `emerald` | The Emerald Dream: deep moss and forest greens, soft cream text, jade accent, bark or old-gold frames, leaf or vine corner art. |
| `void` | The Void: near-black indigo, cool lavender-white text, a vivid void-violet accent (more saturated and darker than Cartographer's muted purple), starfield grain, tendrils in the corner art. |

Agents pick their theme's label, palette, art and (optionally) fonts within the brief.

## Rules for each theme agent

- Own files only: `Themes/<Key>.lua`, `Media/Theme/<Key>/`, `tools/themes/<key>.py`, and any new font files
  (`Media/Fonts/`, unique names, with their OFL license text). No edits to shared files (Core, Panel, tests, TOC,
  README, CHANGELOG); anything a theme needs from them goes into the agent's report.
- Art is generated by the theme's Python script (Pillow, fixed seed, power-of-two RGBA TGA, white art tinted by a
  role), like `tools/theme_art.py`.
- Fonts only from Google Fonts (OFL), static instances, with the Cartographer pattern for client languages (own
  font only where it has the glyphs; Korean and Chinese always keep the client's).
- `lua Tomte/tests/test_theme.lua` (and the whole suite) passes; the agent renders a preview PNG of a panel with
  the palette and looks at it.
- No commits. New media files need a full client restart, not `/reload`.

## Added during review

- `label` font role (buttons, nav category headers, the Almost Done caption); defaults to the theme's title font.
  Classic and Emerald set it to the client font (old buttons used it; Uncial is too ornate at 10–11 pt).
- `art.glowTint`: a color role tinting the top-left glow (Frost and Void use `accent`; Forge bakes ember color into
  its own glow file).
- `fontBump` only applies to Tomte's own font files, not to a game-font fallback (ruRU titles).

## Review

Claude checks each theme against the brief and the rules, runs the full suite, looks at the previews side by side
for distinctness and readability, fixes small issues directly, writes the CHANGELOG line and README credits, and
reports with an in-game test list.
