# Redesign ("Cartographer" theme) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Tomte's dark-flat-gold look with the "Cartographer" theme everywhere, through one theme layer.

**Architecture:** `Core/Theme.lua` holds color roles, font roles (with a client-language fallback) and art paths.
`Panel/Widgets.lua` (`ns.UI`) draws panels, titles, bars and controls from those roles. Every module then stops
hardcoding colors and fonts and asks for roles. Art and fonts are generated by `tools/theme_art.py`.

**Tech Stack:** WoW retail 12.1 Lua (5.1), Python 3 + Pillow + fontTools for art, Lua 5.1 unit tests in `tests/`.

**Spec:** `docs/superpowers/specs/2026-10-10-redesign-design.md`

## Global Constraints

- Client 12.1.0, `## Interface: 120100`. No libraries. Namespace `local addonName, ns = ...`; no new globals.
- Look only: no layout or behavior changes. Sizes, anchors and spacing stay unless a new font needs a size nudge to
  keep the same visual size (Cinzel/Alegreya run smaller than Friz/Arial at the same point size: +1 is allowed).
- Not themed: item quality, class, faction/reputation, chat-type colors (read `ChatTypeInfo`), Blizzard frames and
  tooltips, the Blizzard nav arrow, money icons.
- Text other players wrote uses `ns.Theme.Font("chat")`.
- No commits before the user's in-game check (CLAUDE.md). Work stays uncommitted on branch `redesign`.
- Credits for Cinzel and Alegreya in README; OFL texts ship next to the fonts.

## Review Focus

1. **UI scale below 1 and odd window sizes**: the frame rules and the 1 px inner rule must stay exactly one screen
   pixel (reuse `UI.Border`'s unsnapped pixel code); the grain must tile, not stretch, when the window is resized.
2. **Window opacity setting** (Tomte window → Background opacity) must still change the panel fill alpha live.
3. **Russian / Korean / Chinese clients**: no Cinzel/Alegreya where the client can't render it (test pins the table).
4. **Status colors keep their meaning**: everything that was red/green/orange still reads as missing/done/soon
   (danger/success/warning), and item-quality-colored names are untouched.
5. **Inline `|cff` escapes** in strings (95 of them) are easy to miss: they move to `UI.Hex(role)` / `UI.Wrap`.

### Task 1: Art and fonts generator

**Files:**
- Create: `tools/theme_art.py`
- Create (generated): `Media/Theme/Grain.tga`, `Media/Theme/Contours.tga`, `Media/Theme/Flourish.tga`,
  `Media/Fonts/Cinzel-Medium.ttf`, `Media/Fonts/Alegreya-Regular.ttf`, `Media/Fonts/AlegreyaNumbers-Regular.ttf`,
  `Media/Fonts/OFL-Cinzel.txt`, `Media/Fonts/OFL-Alegreya.txt`

**Interfaces:** Produces the eight files above at those exact paths.

- [ ] Step 1: Script takes `--fonts-src DIR` (the downloaded `Cinzel[wght].ttf`, `Alegreya[wght].ttf`, OFL files) and
  writes everything under the addon root. Uses a fixed random seed so output is reproducible.
- [ ] Step 2: Grain: 128×128 RGBA, per pixel gray `v` = 128 ± noise (Gaussian, σ≈40), alpha = |v-128|·1.6 clipped,
  wrapped so it tiles (generate on a torus: blur with wrap-around).
- [ ] Step 3: Contours: 512×512 RGBA, origin at bottom-right; rings every 18 px with radius wobble
  `r + 3·sin(3θ+k) + 2·sin(7θ)`, 1.2 px anti-aliased lines, white, alpha fading linearly to 0 at radius 500.
- [ ] Step 4: Flourish: 256×16, white diamond-to-hairline (center diamond 8 px, lines fading to the ends).
- [ ] Step 5: Fonts via `fontTools.varLib.instancer`: Cinzel wght=500, Alegreya wght=400. Numbers: copy of the
  Alegreya instance, cmap for `0`-`9` → `zero.tf`…`nine.tf`, family name "Alegreya Numbers Tomte", unique ID and
  full name renamed.
- [ ] Step 6: Verify: open each TGA with Pillow (size, mode RGBA, uncompressed); open each TTF with fontTools; print
  the digit advance widths of the Numbers font (all equal).

### Tasks 5-8: Module migration (parallel, disjoint files)
